API 调用

SciDataIndex 对外开放科学数据集智能检索 API。持有 API Key（令牌）即可通过互联网调用，返回相关数据集列表；精准模式下额外返回候选关系图结构。

核心能力：自然语言检索 · 快速向量召回 · 精准图谱推理与 LLM 重排

🔐 API 获取

填写邮箱与用途提交申请，审核通过后查询码将发送至您的邮箱。一个邮箱固定绑定一个 API Key。

输入申请时填写的邮箱和邮件中收到的查询码，即可获取您的 API Key。

🔌 接入信息

Base URL

http://47.103.128.241:8001

当前 demo 阶段使用 IP 直连。所有接口路径均基于此 Base URL。

POST /api/v1/search

鉴权方式

请求头携带 Bearer API Key：

Authorization: Bearer <你的API Key>

无 API Key 或 API Key 无效将返回 401。

限流规则：每个 API Key 每分钟 30 次；全局每日 100000 次。超限返回 429。

💻 调用示例

快速模式（默认）

curl -X POST http://47.103.128.241:8001/api/v1/search \
  -H "Authorization: Bearer <你的API Key>" \
  -H "Content-Type: application/json" \
  -d '{"query":"我想寻找生命科学数据安全高风险研究相关的数据集","top_k":10}'

精准模式（加 "precise": true）

curl -X POST http://47.103.128.241:8001/api/v1/search \
  -H "Authorization: Bearer <你的API Key>" \
  -H "Content-Type: application/json" \
  -d '{"query":"我想寻找生命科学数据安全高风险研究相关的数据集","top_k":10,"precise":true}'
import requests

resp = requests.post(
    "http://47.103.128.241:8001/api/v1/search",
    headers={"Authorization": "Bearer <你的API Key>"},
    json={
        "query": "我想寻找生命科学数据安全高风险研究相关的数据集",
        "top_k": 10,
        "precise": True,  # True=精准模式(约30-60s)；False/省略=快速模式(<1s)
    },
    timeout=120,  # 精准模式需设置较长超时；快速模式可设短些
)
data = resp.json()

if data.get("ok"):
    for item in data["results"]:
        print(item["name"], item["score"], item["category"])
        print("  来源:", item["source_link"] or "无", " 下载:", item["download_link"] or "无")
    if data["precise"]:
        graph = data["graph"]  # {"nodes": [...], "links": [...]}
        print(f"图节点数: {len(graph['nodes'])}, 边数: {len(graph['links'])}")
else:
    print("调用失败:", data.get("error"))
Windows PowerShell 中 curl 是 Invoke-WebRequest 的别名，语法不同。请使用 curl.exe（全名），并把 JSON 写入文件后引用，避免转义与中文乱码问题。

第一步：创建请求体文件 body.json（UTF-8 编码）

'{"query":"我想寻找生命科学数据安全高风险研究相关的数据集","top_k":10,"precise":true}' | Out-File -Encoding utf8 body.json

第二步：用 @body.json 引用发送

curl.exe -X POST http://47.103.128.241:8001/api/v1/search -H "Authorization: Bearer <你的API Key>" -H "Content-Type: application/json" -d "@body.json"
无需手动处理 JSON 转义，自动处理中文编码，返回自动解析为对象。
$headers = @{
    "Authorization" = "Bearer <你的API Key>"
}
$body = @{
    query   = "我想寻找生命科学数据安全高风险研究相关的数据集"
    top_k   = 10
    precise = $true        # $true=精准模式；$false/省略=快速模式
} | ConvertTo-Json

$response = Invoke-RestMethod -Uri "http://47.103.128.241:8001/api/v1/search" `
    -Method Post -Headers $headers -Body $body `
    -ContentType "application/json; charset=utf-8" -TimeoutSec 120

# 查看结果
$response.results | Format-Table name, score, category
$response.graph.nodes    # 图节点（仅精准模式有数据）
$response.graph.links    # 图边（仅精准模式有数据）
若 PowerShell 中文显示乱码，先运行：[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

📥 请求参数

参数类型必填默认说明
querystring是—检索需求描述（自然语言，中英文均可）
top_kint否10返回结果数量，上限 10
precisebool否false是否开启精准检索（LLM 重排 + 图推理）

两种检索模式对比

快速模式（precise=false，默认）精准模式（precise=true）
原理纯 Embedding 向量召回双路召回 + 概念图多跳推理 + LLM 重排
LLM 调用无2 次
耗时<1 秒约 30-60 秒
graph 字段空结构完整候选关系图
score 含义余弦相似度（0-1）LLM 重排分数
两种模式的 score 含义不同，不可直接比较。快速模式适合快速粗排，精准模式适合需要高精度与图谱分析的场景。

📤 返回结构

{
  "ok": true,
  "query": "检索需求描述",
  "precise": false,
  "elapsed": 0.3,
  "results": [
    {
      "dataset_id": "aps/super_glue",
      "name": "数据集显示名",
      "category": "computer_science",
      "score": 0.86,
      "description": "数据集简介",
      "source_link": "https://数据集官网/来源页",
      "download_link": "https://数据集下载页"
    }
  ],
  "graph": {
    "nodes": [ ... ],
    "links": [ ... ]
  }
}

字段说明

ok请求是否成功
precise本次检索所用模式（true 精准 / false 快速）
elapsed耗时（秒）
resultsTop-K 数据集列表，两种模式结构一致
results[].source_link来源链接（官网/数据页 URL，无有效值时为空字符串）
results[].download_link下载链接（无有效值时为空字符串）
graph候选关系图 {nodes, links}。快速模式为空结构；精准模式含数据集与概念节点及边，可用于图谱可视化
本接口不返回科学问题分析（analysis），以降低响应延迟与调用成本；完整分析请使用网页端「任务检索」。

⚠️ 错误响应

统一错误格式 {"detail": "错误原因"}，HTTP 状态码：

状态码含义说明
401缺少或无效的 API Key检查请求头 Authorization: Bearer <API Key> 是否正确
429触发限流每个 API Key 每分钟 30 次 / 全局每日 100000 次
422请求体格式错误检查 JSON 是否合法、参数类型是否正确

业务级错误（服务内部）返回 {"ok": false, "error": "具体原因"}，HTTP 状态码 200。

📌 使用建议

1. 先用快速模式探路：precise=false 亚秒级返回，适合快速浏览候选、调试查询语句。

2. 需要精度再开精准模式：precise=true 经过 LLM 重排与图谱推理，结果更精准，但耗时 30-60 秒，请设置足够超时。

3. 遵守限流：每个 API Key 每分钟 30 次，请合理安排调用频率，避免触发 429。

4. 妥善保管 API Key：API Key 即访问凭证，请勿公开张贴或写入公开代码。

本 API 引用的科学数据信息均基于互联网智能搜索技术挖掘，检索与评分结果仅供参考。
